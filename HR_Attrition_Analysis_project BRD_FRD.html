Part A — Business Requirements Document

1. Executive Summary

Business context, problem statement, and project background

📊
Project Overview

This BRD defines the business needs, objectives, scope, and requirements for the HR Employee Attrition Analysis Project. The project delivers an interactive Excel-based dashboard enabling HR leadership and business stakeholders to monitor, analyze, and take action on employee attrition trends across the organization.

The organization has experienced significant employee turnover impacting operational continuity, recruitment costs, and organizational knowledge retention. This project addresses the critical need for data-driven insights into attrition patterns to enable proactive workforce management.

1.1 Problem Statement

  • High employee turnover rate with insufficient visibility into root causes
  • Manual and inconsistent attrition reporting across departments
  • Inability to identify at-risk employee segments proactively
  • Lack of standardized KPIs to track HR health metrics
  • No centralized view correlating attrition with compensation, satisfaction, and tenure
  • Limited ability to benchmark attrition by department, gender, age, or job role

1.2 Project Background

The HR department maintains a comprehensive employee dataset covering 2,000+ employees across multiple departments, roles, age groups, and locations. Currently, attrition reporting is manual, time-consuming, and lacks the visual and interactive capabilities needed for rapid decision-making.

2. Business Objectives & Success Criteria

🎯
Business Objectives
  1. Develop an interactive, self-service HR analytics dashboard with real-time visibility into attrition trends

3. Project Scope

✅
3.1 In Scope
  • Interactive Excel dashboard with 5 Key Performance Indicators (KPIs)
  • Attrition analysis across all departments: R&D, Sales, HR
  • Gender-wise attrition rate visualization and comparison
  • Department-level attrition breakdown and trending
  • Age group segmentation: Under 25 / 25-34 / 35-44 / 45-54 / Over 55
  • Employee status: Current Employees vs. Ex-Employees
  • Job role-level attrition analysis across all 9 job titles
  • Travel frequency impact analysis on attrition
  • Education field and degree level correlation
  • Marital status impact analysis
  • Interactive slicers and filters for dynamic data exploration
  • Formatted, print-ready reporting views
🚫
3.2 Out of Scope
  • Predictive machine learning models for attrition forecasting
  • Real-time integration with HRIS systems
  • Employee-level individual PII reporting
  • Automated email alerting or notification systems
  • Mobile application development
  • Integration with payroll, benefits, or recruiting systems

7. Assumptions, Constraints & Risks

📌
7.1 Assumptions
  • All stakeholders have Microsoft Excel 2016 or later with full feature support
  • The provided dataset is a complete and accurate extract of the HR system of record

KPI Formulas & Card Design

F8. Data Refresh Procedure

🔄
Monthly Refresh Steps
  1. Export updated HR dataset from HRIS in CSV or Excel format
  2. Open dashboard workbook with analyst credentials
  3. Navigate to Raw Data sheet and unlock with analyst password
  4. Delete existing data from Row 2 downward (preserve header row)
  5. Paste new data into Raw Data sheet starting from Row 2
  6. Verify row count matches expected employee count (sanity check)
  7. Navigate to Pivot Tables sheet — right-click — Refresh All
  8. Return to Dashboard and verify KPI cards show updated values
  9. Update "Last Refresh Date" cell in dashboard header
  10. Save file and re-apply sheet protection
  11. Distribute updated file via approved channel
✅
Data Validation Checks
🔢
V-001: Row Count
Total records match HRIS export count
🔤
V-002: Attrition Values
Only "Yes" or "No" values present
🏢
V-003: Department Values
Only R&D / Sales / HR accepted
📅
V-004: Age Range
All values between 18 and 65
➕
V-005: KPI Consistency
Active + Attrited = Total Employees
🆔
V-006: No Blank IDs
All rows have unique Employee Number
