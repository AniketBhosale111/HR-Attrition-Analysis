# HR-Attrition-Analysis
## Project Overview
 the main objective of HR Employee Attrition Analysis Project are to analyze the all employees data and finding the meaningful insights of some business problems required statement like why employee leave this company what will be rezone of that.

for this project I have used HR employee's dataset contains 1500+ employees records like department, employee job role, status, income and attrition rate of employee
